# 物料模板、导入与品牌命名的确认边界

日期：2026-09-15。知识基线：0.3.18。来源工作树：J0WMS/gmp-platform；目标：Zencas/gmp-platform。

用户原话（user-confirmed）：“把当前品牌字段也改成 `brandName`，然后移植F04a、F04b、O01、O02”。F04a 是物料 Excel 模板，F04b 是物料批量导入；O01 是按服务端总数展示物料分页总数，O02 是按既有数组响应展示首页待办和已办。

移植边界来自已批准功能及来源原始代码（original-evidence）：模板使用 `.xlsx`，单次最多 1000 数据行；校验合法的新物料保存，重复料号和版本跳过，无效行返回行号与原因，可在一次导入中返回成功、跳过、失败三类结果。目标已有 DEC-0048 确认物料类型必填、品牌选填，该语义继续适用于导入。物料类型选择来自目标字典，不将来源固定的类型清单作为目标业务规则。

品牌 `brandName` 是字段命名变化，仍指同一物料品牌，不能据此新建第二个品牌概念。追加迁移把旧 `brand` 列重命名为 `brand_name`，保留已有值和空值；既有 0078 迁移和历史审计 JSON 不重写。请求兼容旧 `brand` 别名、新响应使用 `brandName`，属于本切片的兼容实现选择。

来源服务检查位置：`backend/src/main/java/com/zencas/edhr/masterdata/service/MaterialImportService.java` 的 `createTemplate`、`importWorkbook` 和 `parseRow`，于 2026-09-15 核对原始源码。来源允许空类型，移植时必须以目标类型必填规则为准。来源不校验新增版本与数据库既有基础信息的一致性；目标实现对冲突行返回失败，以保护当前基础信息更新路径。此一致性处理、去空格和大小写归一化属于实现解释，不提升为新的通用业务规则。

逐行失败仅指可识别的输入校验失败；数据库、审计或工作簿异常仍遵循控制器事务失败回滚，不能解释为任何基础设施异常都允许部分提交。待办、已办继续由服务端当前登录身份决定，不接受客户端指定他人身份扩大查询范围。生产、库存、BOM 规则与历史快照不在本次变更范围。

本记录只建立确认来源和实现核对边界，不代表浏览器、运行数据库、发布或独立质量验收已经通过。

## 2026-09-16 模板指引增量

知识基线：0.3.21。用户明确要求（user-confirmed）：“物料管理下载的模板和内容需要更新，必填项要在模板里用 * 标注，同时物料类型是下拉，选型都内置进去，物料用途也是”。该要求补充模板呈现，不替代原有导入规则。

目标原始实现（original-evidence）：`MaterialImportService.parseRow` 必填名称、料号、类型和版本；品牌选填；用途可空，空值解析为生产物料，合法用途为试验物料和生产物料。`createTemplate` 将四项必填表头加星号，类型使用当前字典、用途使用既有枚举，两列选项随工作簿内置并通过命名区域数据验证提供下拉。`validateHeaders` 同时接受带星号的新表头和原无星号表头。填写说明、输入提示和列表外值提示不新增业务限制，后端原校验仍是导入约束。

实现修复推断（inference）：主智能体现场查证现有 `material_type` 为空，而历史 `0015-material-versioning.sql` 已初始化五项标准类型且界面仍提供同一清单。因此追加 `0087-restore-standard-material-types.sql` 按默认租户内名称或编码是否已存在补缺既有原材料、半成品、产成品、辅材和包材，任一匹配即保留，不覆盖已修改配置或自定义类型。精确 `validCheckSum` 仅兼容本轮本地已执行的旧版本；名称与编码双重判断避免标准编码已被重命名时触发唯一约束冲突。此处只记录历史初始化恢复的依据，不能提升为用户新确认的固定业务分类，也不允许导入时自动创建任意类型。

缺陷定位（original-evidence）：`createTemplate` 在类型列表为空时不创建类型数据验证，这解释了当前模板缺少类型下拉；用途原本已有内置选项。不能把 POI 方法名直接解释为隐藏箭头：现用 XSSF 的 `setSuppressDropDownArrow(true)` 输出 XML 为 `showDropDown=false`，本次保留该设置并增加 XML 回归断言，而非将其误报为缺陷原因。

证据边界：工作簿 XML/POI 检查可以验证星号、内置列表、范围与下拉设置，不能单独证明 Excel 桌面软件交互。新旧模板导入、迁移幂等、下载运行态和独立验收须按各自证据说明；本次不改变权限、审计、生产数据或历史快照，知识保持 implemented/internal。
