## 已确认语义

1. 表单实例号标识一份具体填写的记录，与模板编号、模板版本、内部数据 ID 区分。系统在首次创建并保存记录时生成，同一租户内跨模板唯一，不可修改、不重复使用。格式为 `FR-YYYYMMDD-流水号`；示例 `FR-20260915-000123`。
2. 同一份记录的保存、提交、审批、退回修改保持实例号不变；复制后新建另一份生成新号。子表多行明细归属同一表单实例，不分别生成实例号。模板发布新版不改变已有实例号。
3. 填报记录列表把实例号作为固定首列，支持查询、复制和点击详情，不作为用户可编辑业务字段。详情显示表单名、实例号、实际使用的模板版本及冻结表单内容。
4. 编号是可读身份，内部 ID 继续用于数据关联；查询和详情不能绕过授权。

- inference：当前可核对的真实填写链路位于 `ProductionExecutionService`，`ModelTab` 原列表为空数组。以每份已保存生产执行表单建立模板级索引是本次实现选择；不能推导其他填报来源已全部接入。
