# 工序模板下载与导入的确认边界

日期：2026-09-16。知识基线：0.3.21。决策包：DEC-PACKAGE-20260916-OPERATION-IMPORT。

用户明确要求（user-confirmed）：“按照物料管理导入的标准，在工序管理中新增下载模板和导入数据功能”。主智能体说明标准包括 xlsx 模板、必填标记、示例、填写说明、分类与工序类型下拉、1000 条上限、必填和长度及取值校验、按编码跳过重复、三类结果与逐行原因、列表及分类统计刷新、成功审计与异常整批回滚后，用户回复：“恢复项目门禁并继续实现”。

继承标准（original-evidence）：DEC-0049 与 MaterialImportService、ProcessModelingController 的物料入口定义现有模板和逐行导入边界。成功、跳过、失败反映可识别的输入处理结果，数据库或审计异常不属于可继续部分提交的逐行失败。工序新增入口已经维护分类和 CREATE 审计，本次增加批量入口，不产生第二套工序概念。

实现选择（inference）：主智能体按现有工序表单选择七项字段，沿用现有新增时的分类建立、类型和状态默认值；导入工时表达为非负整数分钟，状态显示启用/禁用。编码去空格和忽略大小写去重、分类匹配属于与现有数据及新增流程一致的实现处理，不单独提升为用户明确指定的通用业务规则。分类下拉提供现有选项，不能据此声称未列出的分类一律属于非法输入。

影响边界：工序导入只新增合法工序，重复编码不覆盖已有数据；不修改物料导入、工艺路线引用或生产实例和历史执行快照，不新增数据库迁移或独立权限体系。新增接口应沿用现有认证及权限边界；该陈述不等于已经完成全部角色权限矩阵验证。

证据边界：源码、工作簿结构检查、测试源码、测试运行、隔离 API/数据库、部署后的浏览器和 Excel 桌面交互分别提供不同证据。当前知识记录保持 implemented/internal，不进入客户或运行时投影，不伪造 verified 执行契约；具体运行结果由本次主智能体与独立质量结果提供。
