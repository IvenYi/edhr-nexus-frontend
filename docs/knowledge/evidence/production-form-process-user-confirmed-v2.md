# 生产表单流程配置用户确认（当前方案）

日期：2026-09-02

本记录是用户确认的当前配置模型证据，不代表生产运行时已经实现。

- 表单流程必须可以复用到多个表单；表单流程模板不绑定具体表单。
- 表单流程节点只配置主体来源和主体默认权限。填报节点可以有多个填报主体；审批节点配置审批主体。默认权限只有“全部可编辑”和“全部只读”。
- 新配置不使用流程字段、字段槽位、业务字段分类、字段权限组或权限模板。
- 作业流程的表单填写节点固定绑定一个已发布表单流程版本和一个具体表单模板版本。绑定后，用户可针对该表单实际存在的稳定 `fieldId` 配置例外权限，例外值只有编辑或只读。
- 未配置例外的真实表单字段继承对应主体的默认权限；每个表单绑定独立保存例外权限，不能反向修改可复用的表单流程版本。
- 已发布表单流程版本固定，不在原版本上修改；需要变化时创建新版本。
- 审批候选人任一人处理即可完成节点；顺序审批通过配置多个审批节点实现。第一版不设置拒绝动作，退回固定回到填报阶段；表单流程终止时同步终止外层作业流程。
- 审批主体和填报权限主体共用公共主体选择器，第一版支持用户、部门和角色并允许多选；当前不开放用户组、部门负责人和业务责任人。
- 部门主体默认覆盖本部门及下级部门，也可切换为仅本部门，选择结果需要明确显示范围。
- 角色和部门不在流程发布或业务启动时固定成员快照。审批节点到达时按最新关系解析候选人，填报权限在用户访问时按最新关系判断。
