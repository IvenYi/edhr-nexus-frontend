# DHR 管理第一期已确认边界

本记录对应 2026-09-17 的用户确认与 `DEC-PACKAGE-20260917-DHR-MANAGEMENT-PHASE1`，只保存当前功能切片的业务边界。

- BATCH 和 SN 生产对象均在首次合法 `START` 时自动创建唯一 DHR 实例，禁止手工创建。
- DHR 创建与生产开工属于同一事务；任一环节失败时整体回滚。
- DHR 创建时冻结工单、产品、生产对象、产品制程版本、工艺路线版本、DHR 模板版本和目录快照；后续模板变化不改写既有实例。
- DHR 第一阶段只聚合 `PRODUCTION_EXECUTION` 来源表单记录中具有 `dhrItemId` 的证据；每个 `copyId` 对应的份分别保留。工序/DHR 绑定、作业发起和自定义挂载是独立表单实例来源；只有前者携带目录项，同模板版本不构成复用或证据转移依据。
- DHR 创建状态为 `IN_PROGRESS`；同一生产执行动作完成全部工序时更新为 `COMPLETED`。
- 本期提供 DHR 列表与只读详情，菜单权限为 `records.dhr-management`，查看权限为 `dhr.instances.view`；初始化仅默认授予管理员。
- 进入 DHR 闭环的生产执行若缺失关联实例，必须阻断完成并回滚当前动作。
- DHR 汇总审批、退回、发布、归档、作废、拖拽和人工补充证据均不属于本期。

本文件是用户确认的知识证据，不证明代码、数据库迁移、页面或测试已经完成，也不把未来审批与发布能力提升为当前规则。
