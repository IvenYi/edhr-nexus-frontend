# 表单实例业务来源语义确认

knowledgeModelVersion: `0.3.20`

## 已确认结论

- 全局表单实例列表的“来源”表示表单实例创建时冻结的**业务承载域**，用于查询、授权和产品展示；它不是工序配置、作业发起或自定义附件等表单进入方式。
- 当前已实现的表单实例都由生产执行产生，因此本切片唯一的业务来源值为 `PRODUCTION_EXECUTION`，客户展示为“生产执行”。
- 工序配置、作业发起和自定义附件继续是生产执行内部的表单入口类型；它们不能替代全局实例来源，也不能由全局列表按表单 ID 前缀推断。
- 后续非生产模块接入统一实例目录时，必须在创建实例时写入自身业务来源，并同步设计对应授权、审计、快照和查询适配；本次不预先定义这些来源枚举。

## 证据边界

本结论由用户在当前产品讨论中确认。主智能体已对冠骋可获得的原始前后端源码进行交叉核对：其列表来源列使用持久化业务类型，而非表单进入方式。冠骋源码位于本仓库外，不满足本仓库 `evidence.path` 相对路径和存在性策略，因此不在结构化 evidence 中写入外部绝对路径；本文件只保留用户确认的 eDHR 产品结论。eDHR 当前源码和迁移证据仅证明现有记录都属于生产执行，且尚未持久化该业务来源字段，不能据此宣称本次新增列已经落地。
