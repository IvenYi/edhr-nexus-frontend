# 记录控制中文产品术语确认

knowledgeModelVersion: `0.3.18`

## 证据类型

`user-confirmed`

## 已确认结论

- 当前产品和后续沟通统一使用“表单变更、表单作废、转办、重新分配、退回”五个中文动作名称。
- 在记录控制上下文已经明确时，“表单变更”和“表单作废”可以简称为“变更”和“作废”。
- “更正”“普通转办”“管理重新分配”不再作为并列的现行中文产品动作名；新文档、页面文案、接口说明和验收用例不得继续传播这些旧称。
- `correction`、`CHANGE`、`OBSOLETE`、`TRANSFER`、`RETURN`，以及既有 Java 类名、数据库字段、接口字段和权限码，是稳定技术标识。本次中文术语治理不授权破坏性重命名或数据迁移。

## 适用边界

- CAPA 领域的“纠正措施”具有独立法规语义，不改名。
- “请求被拒绝”“拒绝冲突的幂等请求”等普通结果描述不是记录控制动作名称，不改写为“退回”。
- 历史中文旧称只可在说明其已废弃时出现，不作为检索别名或现行产品名称继续投影。

## 证据来源

以上结论来自 2026-09-15 当前产品讨论中的用户明确确认。本证据只规范产品语言，不改变运行时路由、生命周期状态、生产快照、审计历史、权限或电子签名规则。
