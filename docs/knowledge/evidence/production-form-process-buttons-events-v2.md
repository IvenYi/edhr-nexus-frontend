# 表单流程按钮与内置事件配置（当前方案）

日期：2026-09-02

本记录是用户确认的配置层范围，不代表表单流程实例或生产运行时已经实现。

- 表单流程节点提供“按钮配置”入口。第一版只保存按钮是否可见、标准动作及动作参数；产品层不再单独配置“启用”。
- 保存、提交、审批、退回按钮可配置是否需要电子签名；电子签名要求属于按钮动作配置，未要求时不触发签名采集。
- 第一版标准动作白名单为：保存（`SAVE`）、提交（`SUBMIT`）、审批（`APPROVE`）、退回（`RETURN`）。
- 转交、加签、拒绝、终止、撤回及其同义动作第一版不开放配置。
- 表单流程节点提供“节点事件配置”入口。事件保存执行前或执行后的时机、关联按钮动作和内置事件类型；第一版内置事件仅支持“填充签名字段”（`FILL_SIGN_FIELD`）。
- 处理标识、处理器标识等技术字段不属于用户配置项，也不再作为事件配置持久化字段。
- “填充签名字段”在可复用表单流程版本中只声明事件，不绑定具体表单字段。作业流程的表单填写节点选定具体表单模板版本后，按事件标识绑定该表单真实存在的稳定 `fieldId`；绑定属于作业节点，不回写表单流程版本。
- 发布或保存绑定时，事件标识必须来自所引用的已发布表单流程版本，字段标识必须来自所选表单模板版本；版本切换后失效绑定不能继续保存或生效。
- 按钮和事件声明属于表单流程版本配置数据；已发布版本只读，修改必须形成新版本。作业节点的字段绑定属于作业流程配置快照。
- 冠骋资料仅作为竞品/历史参考（`secondary-reference`）；它不能证明 eDHR 当前已有对应的运行时动作或事件执行契约。
