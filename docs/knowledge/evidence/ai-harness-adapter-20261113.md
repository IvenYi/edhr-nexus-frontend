## 本次原始源码核对

- `gmp-platform/ai-worker/src/client.mjs`：部署方提供固定服务地址及 Worker 凭据，只暴露领取、续期、原生表单读取/写入和回执查询路径；禁止重定向，凭据不由模型工具参数提供。
- `gmp-platform/ai-worker/src/form-plugin.mjs`：工具绑定领取的 task/run/leaseEpoch 和 DSH session；模型参数不能指定业务用户、目标或代际。保存使用刚读回的修订；本地待确认标记只保存操作身份，结果未知阻断继续执行并查服务端回执。
- `gmp-platform/ai-worker/test/form-plugin.test.mjs`：存在任务隔离、参数拒绝、当前读取、未知结果、卸载与传输边界测试代码。测试文件存在不是通过证据；版本升级、运行及独立质量结论由主侧本切片验收提供。

以上为 `original-evidence` 的源码核对。受控适配层连接已有 Java 动作，不重新定义业务含义；确定性权限、原生事务与回执仍在 `AiTaskService` / `AiFormService`。本地 pending 标记是恢复辅助材料，不是已发生业务事件，不替代持久可读运行日志。
