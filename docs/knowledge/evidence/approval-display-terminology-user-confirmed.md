# 审批语义客户展示术语统一

knowledgeModelVersion: `0.3.20`

## 证据类型

`user-confirmed`

## 已确认结论

- 审批决策语义的页面、菜单、任务和流程配置统一使用“审批”；表单审核和 DHR 审核在表达审批动作时使用“表单审批”和“DHR 审批”。
- 流程中心原“审核流程模板”菜单/页面展示名改为四字“审批流程”，去掉“模板”；稳定路由、权限码、接口路径和技术标识不改。
- 非决策性的检查、评审、审计等语义继续使用原词，不因本次展示术语治理机械替换。

## 证据边界

本证据记录的是 2026-09-16 产品讨论中用户确认的客户展示术语，不证明 DHR 审批运行时页面、任务或执行引擎已经实现。现有 `REVIEW`、`REVIEW_PENDING`、`IN_REVIEW`、`APPROVAL`、`APPROVE` 等代码枚举，以及 `/workflow/review-templates` 等路由和权限标识均属于稳定技术契约，不在本次术语调整范围内。历史决策和历史审计记录保留原始用词，仅当前产品投影与后续新文档采用统一术语。
