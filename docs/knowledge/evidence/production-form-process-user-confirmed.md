# 生产表单流程配置用户确认（历史方案）

日期：2026-08-31

本记录保留早期用户业务讨论的知识证据索引，不是当前配置方案，也不是生产运行时实现证据。当前方案见 `production-form-process-user-confirmed-v2.md`，并由 DEC-0023 supersede DEC-0022。

- 表单流程模板不绑定具体表单；流程模板通过字段槽位与表单模板版本解耦。
- 作业流程的表单填报节点固定选择一个表单模板版本和一个流程模板版本，并形成一个绑定版本。
- 填报阶段支持多个权限组，按岗位、角色或用户组配置字段权限和保存、提交等操作权限。
- 审批阶段以审批节点解析出的参与者作为权限主体，支持固定用户、部门负责人、角色/用户组和业务责任人等来源。
- 字段权限第一版只有编辑和只读；没有特殊规则的字段默认编辑；同一人员命中多条规则时只读优先。
- 审批候选人任一人完成即可；需要顺序审批时通过配置多个审批节点实现。
- 第一版不设置拒绝动作；退回固定回到填报阶段；终止表单流程时同步终止外层作业流程。
