# 表单流程按钮电子签名配置（当前确认）

日期：2026-09-03

本记录是用户确认的配置层范围，不代表表单流程实例、电子签名采集或运行时事件执行已经实现。

- 按钮只配置“显示/不可见”，不提供单独的“启用”勾选；不需要按钮事件时直接删除事件配置。
- 电子签名作为独立的签署事件配置，开始节点关联保存（`SAVE`）或提交（`SUBMIT`），审批节点关联审批（`APPROVE`）或退回（`RETURN`）。
- 签署事件固定使用账户密码并在动作执行前处理；事件存在即表示需要签名，不再额外配置启用状态。签名字段在作业流程表单填写节点绑定。
- 表单流程版本只保存按钮的电子签名要求和事件声明；具体签名字段仍由作业流程表单填写节点绑定所选表单模板版本的稳定 `fieldId`。
- 冠骋资料仅作为竞品/历史参考（`secondary-reference`），不能证明 eDHR 当前已经实现电子签名采集、动作阻断或签名字段写入。
