# 表单流程主体默认权限与绑定级字段例外（当前方案）

本记录对应当前表单流程配置投影，不代表生产运行时已实现。

- 表单流程模板只保存节点主体来源及主体默认权限，默认权限为全部可编辑或全部只读。
- 作业流程的表单填写节点绑定具体表单模板版本后，直接从该版本读取真实字段清单；例外权限以稳定 `fieldId` 保存，值为编辑或只读。
- 未配置例外的字段继承主体默认权限。例外属于绑定配置，不回写或改变可复用的表单流程版本。
- 流程字段、业务字段分类、字段权限组和权限模板不属于当前用户配置入口。
- 填报节点的“全部可编辑/全部只读”是主体默认权限的批量设置；即使当前没有主体，操作也必须落到可读取的真实配置，不能只更新临时展示。
- 切换绑定的表单模板版本或表单流程版本时，系统只保留新表单真实存在且仍对应新流程主体的 `fieldId` 例外；失效例外必须清理或阻止保存。
