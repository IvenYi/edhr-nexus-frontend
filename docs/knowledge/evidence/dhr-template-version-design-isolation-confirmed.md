# DHR 模板设计版本隔离确认

来源：用户确认的决策包 `DHR-template-version-design-isolation-2026-09-18`。

同一批记录模板复制出新版本后，目录和表单引用可以独立保存。从版本行进入“设计”必须打开用户明确选择的 DHR 模板版本；窗口标题、目录、引用表单以及保存请求均以同一 `templateId + versionId` 组合为范围，不能因缓存、默认排序或最新版本回退而读取或修改另一个版本。

该确认只定义模板配置的版本隔离和可追溯引用边界。不改变后端持久化结构、DHR 实例快照定义、审计事件或生产 DHR 实例创建；真实浏览器交互验收仍由用户执行。
