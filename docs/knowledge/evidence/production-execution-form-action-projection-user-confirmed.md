# 生产执行表单流程当前节点动作投影（用户确认）

日期：2026-09-22

来源：用户在生产工作台截图和对话中确认；动作栏与运行时流程节点的源码核对见同目录证据索引。

- 作业填报节点的表单完成首个填报节点并流转到后续审批节点后，运行时不再展示填报节点的“暂存”“提交”按钮。
- 后续审批节点仅展示当前审批节点按钮配置投影的按钮，包括“审批”“退回”“转办”等已配置动作。
- 当前节点的后端动作授权不能由前端显隐替代；填报节点现有的暂存/提交行为仍需保留，服务端执行前必须重新计算当前节点和允许动作。
- 是否使用共享表单渲染组件承载动作按钮以源码为准。本次源码核对显示 `FormCanvasPreview`/`FormDocumentPreview` 负责字段或文档渲染，生产执行页底部动作栏负责渲染 `controls.buttons`。

本记录只证明用户确认的业务行为和源码核对线索，不证明最终修复、运行服务加载或浏览器验收已经完成。
