# 生产表单流程主体可选与开放操作范围用户确认

日期：2026-09-05

本记录是用户确认的主体配置规则证据，不代表生产运行时已经实现。

- 填报主体和填报权限组都不是必填项；未配置时表示所有人都可以填报。
- 审批主体不是必填项；未配置时表示所有人都可以审批。
- “所有人”指当前单租户产品边界内的已认证用户，仍受流程实例、节点状态和任务状态约束，不包含匿名访问。
- 空主体配置不得为了生成候选名单而展开或查询全量用户；审批运行时仍只创建一个逻辑任务。
- 配置了主体时，继续按公共主体解析和多候选任务规则处理；任务创建后冻结已解析候选快照。空主体的开放范围不应伪装成一个全量候选快照。
