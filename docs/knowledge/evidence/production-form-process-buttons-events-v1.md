# 表单流程按钮与节点事件配置（第一版）

日期：2026-09-02

本记录是用户确认的配置层范围，不代表表单流程实例或生产运行时已经实现。

- 表单流程节点提供“按钮配置”入口。第一版只保存按钮是否可见、是否启用、标准动作及动作参数。
- 第一版标准动作白名单为：保存（`SAVE`）、提交（`SUBMIT`）、审批（`APPROVE`）、退回（`RETURN`）。
- 转交、加签、拒绝、终止、撤回及其同义动作第一版不开放配置。
- 表单流程节点提供“节点事件配置”入口。第一版只保存事件时机（`BEFORE`/`AFTER`）、关联动作和可选处理器标识，不声明事件已经可以在运行时执行。
- 按钮和事件配置属于表单流程版本的配置数据；已发布版本仍然只读，修改必须形成新版本。
- 冠骋资料仅作为竞品/历史参考（`secondary-reference`）；它不能证明 eDHR 当前已有对应的运行时动作或事件执行契约。
