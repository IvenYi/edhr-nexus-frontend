# 记录变更首版检索范围用户确认

日期：2026-09-15

来源：用户与主智能体关于“记录变更”产品范围的连续业务讨论确认。

决策演进：

- 初始讨论中，用户曾确认记录变更首版提供“按表单流水号”和“按批次/SN”两种检索方式。
- 最新确认覆盖初始交付范围：为了交期，本次首版只做“按表单流水号”检索并发起变更。
- “按批次/SN”检索延期到后续版本，不是永久取消。
- 本次首版仍不单独提供 DHR 或记录本检索入口。

边界：

- 本证据只确认当前交付和延期范围，不确认前端使用页签、单选项、下拉框或其他具体控件承载。
- 本证据不新增或修改变更审批、签名、作废、前后对比、审计、可变更状态或 DHR 汇总语义。
- 表单流水号查询的结果字段、可变更资格状态和发起变更后的流程尚未在本次确认中定义。
- 按批次/SN检索的结果字段、同一编号关联多个表单时的选择方式和实现版本仍待后续产品设计，不得把延期解释为删除该能力。
