## 影响分析

直接影响为引用配置、来源查询 API、填报控件、首次值初始化、原因主数据、菜单权限及用途报告。传递影响为联动依赖值解析、引用有效性校验、冻结版本解释、来源快照及报表原因筛选。前端展示字符串不得作为 SQL 筛选或原因身份。

兼容和迁移：新目录和权限使用新迁移；既有单展示字段配置按原冻结版本解释，存量实例不被新模板覆盖。已有保存值及历史分类/原因文本不回写、不按同名归并。新增目录状态不应让未变更的历史已选原因因停用而丢失；新选择仍排除停用项。已使用原因删除有保护。

生产快照：上下文来自该生产对象冻结执行配置，工序引用取真实工序主数据 ID，不能使用路线节点 key 充当身份。默认值初始化保存于新副本状态，动态新增行使用同份受控默认值而不预造空行。

审计与权限：目录 CRUD 使用同级目录的审计及身份契约；前端权限展示、后端类型授权和初始化权限必须一致。引用查询沿模板设计/生产执行入口原有授权；人员选择不能通过另一套更宽的用户查询绕开引用条件。

不受影响：最终产出工序、工序/批次/工单的既有数量累计、电子签名、审批、DHR归属及库存动作均沿原契约。原因分项不重算这些数量或状态。

证据缺口：原因件数/缺陷次数、原因重叠及跨原因聚合仍未确认，因此只实现来源明细，不新增推导 NG 或分项总计。目录配置负担仍待客户试用判断；技术交互和独立验证结果见下文，不以设计确认冒称客户验收通过。

扩展路径：`configuration` + `product-core`。引用配置及选择控件归模板/共享填报组件；查询身份及上下文初始化归模板引用服务/执行引擎；原因目录归主数据；投影语义及报告归投影模块。无客户专属页面条件分支，不引入表达式、分类目录、扫码解析或跨字段自动回填。
