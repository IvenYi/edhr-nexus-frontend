## 实际修改

- `SopDocumentRepository`以绑定参数在数据库完成分类与标题/任意版本编码匹配、count和父文档分页；分类数量GROUP BY聚合。
- 局部`DocumentListReadService`只读REPEATABLE_READ事务覆盖count/page/完整本页版本/文件及分类元数据，私有512 ID分批供三个真实读取者复用；没有客户页长上限、跨请求缓存或控制器DTO反向依赖。
- 控制器列表投影复用现成文件map；单记录写入/版本响应和审计路径继续沿原职责。因本次替换而无消费者的内存筛选方法移除。

旧版本编码仍可命中父文档，返回该文档全部版本；`%/_/!/反斜杠/引号`保持字面匹配，中文/ASCII大小写与空白检索有真实接口回归。null更新时间仍优先，同时间用ID稳定分页。保留原分类资格、非正参数归一化、大页空页、缺文件fileId和空属性，不新增历史缺失合法性政策。
