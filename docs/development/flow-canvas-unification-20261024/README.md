## 当前实现

- 路线编辑、产品工作区及产品/产品簇制程预览通过领域适配器调用 `StandardFlowNode`；通用流程原本已使用该组件。开始、结束和普通业务节点采用相同配色、尺寸、文字、选中态与连接点。路线保留并行、汇合、返工徽标及返工红色虚线。
- 路线与表单、审批、作业编辑器直接共用 `FlowCanvasControls`、`FlowHistoryControls`、`FlowMiniMapControl`。缩放、适配、锁定、手形/框选、撤销重做与缩略图处于相同的左下工具区。路线保留可输入缩放百分比；自动整理仍由已有的各通用流程布局处理器负责，未给路线增加自动重排规则。
- 路线全屏编辑接入 `FullScreenFlowDesigner`，使用统一标题和右上保存/关闭区域；左侧版本信息、工序库及右键领域操作保留。审批的右侧节点设置仍归审批领域，不强行改成工序库布局。
- 路线接入既有 `useFlowHistory`：50 步历史、新编辑清除重做、按钮和 Ctrl/Cmd 快捷键、添加/拖动/连线/重连/复制/并行/返工/删除快照、关闭与重新载入重置。三个通用编辑器仍保留各自 dirty、权限、校验、保存和发布处理。
- 前轮提取的 `routeGraph.ts`、`RouteGraphPreview.tsx` 继续供三个路线/产品入口共用。产品图保持结构只读，仅按原回调点选工序配置，不开放图编辑。

保留路线 legacy `route-handle-*` 端口 ID、START 无入/END 无出的原方向范围、节点键、工序身份、关系、条件及既有坐标。节点统一为普通 148×60、边界 96×52；用户新增节点时 END 仍按原避让算法留空间，间距随新尺寸适配。缺省端口按当前几何生成，不承诺极端斜角的推断方向与旧尺寸字节相同；后端路线执行消费 source/target 关系，不消费这些端口（见本轮本体核对）。

存储、版本、执行、审计、生产快照和后端 API 均保持各自机制；没有数据库迁移。产品 `routeNodeKey` 绑定、最终产出、表单和文档配置仍归具体制程版本。
