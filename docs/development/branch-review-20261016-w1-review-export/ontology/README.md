## 汇总修订与A12的所有权不同

汇总修订创建同一DHR下新的整理草稿和后续汇总冻结版本，处理完整证据的编排、核查和批准；受控追加创建新表单实例；继续填写仅对既有未完成自定义份按DEC-0075执行。三者均不授权直接改写已完成表单、旧签署或旧汇总。

表单变更/作废由记录控制域拥有申请、来源资格、签名及正式生效；DHR仅消费已生效来源影响（DEC-0068-04、DEC-0042-01）。DEC-0042-04/05仅有共享动作/事件/处理器端口，不能把接口存在写成申请事务、结果投递及来源落地已完成。DEC-0077-10仍将A12排除在首次最终完成投影闭环的已实现范围之外。表单作废资格等原开放问题继续由相应切片确认，本批不增政策或清除问题。
