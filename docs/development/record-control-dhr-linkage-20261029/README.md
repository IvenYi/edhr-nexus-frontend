## 已确认，另行实施的归档MVP

统一称“DHR归档”。汇总版本冻结、审核定稿、最终放行、归档与下载归档包分别解释，不把审核通过当作放行或归档。本轮只登记，不开发归档操作。

- [ ] 最终放行后绑定正式DHR具体版本及对应表单修订、附件、签名、审计和放行依据。
- [ ] 归档后限制普通修改，保护正式证据；保存归档主体、时间和版本。
- [ ] 保留按权检索、追溯和导出，验证文件完整性与备份恢复；下载ZIP不能替代可靠保存。
- [ ] 定义并验收最小归档执行入口、权限和与放行的衔接，不能只加状态或改名。

独立归档审批、解封及完整放行后变更不在本轮；放行后变更保持P1，未实现前不允许绕普通变更修改已归档记录。打印过滤作废另行设计；DHR目录变更入口、活动表单作废、记录控制撤回／转办／重新分配及A12历史检索UI、规则重建保持既有待办，不由本轮顺带计为完成。
