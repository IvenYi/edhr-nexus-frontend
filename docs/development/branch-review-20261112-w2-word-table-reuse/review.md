## 最小实现及业务边界

产品仅 `importWord.ts` 14增/10减：`importDocxToCanvasPage` 内新建Map；parseBlocks按实际正文XML Element登记本次ParsedTable；图片收集与表格高度累计通过ReadonlyMap读取。每个当前正文顶层表格只解析一次，多个表按自身节点区分，同名文件、下一次导入和并发导入均创建独立Map。

表格解析、XML/关系读取、图位和段落近似、媒体编码、错误行为、.doc/Excel、页面装配及保存协议不改。parseBlocks与collectImageItems读取同一个DOM的正文直接子节点，Map登记与消费边界明确；没有按文件名/ID猜归属、全局缓存、异常吞没或“查不到再重新解析”的兜底层。ParsedTable原块/图位消费者只读，Map只增加引用，不向输出泄露DOM或新的业务字段。

原图文近似（包含部分图片与文字重叠）、原嵌套表表现保持；完整输出一致不等于全部Word版式正确。没有借优化改变布局算法、业务政策、字段完整性/发布门禁、权限、签署、冻结、审计、后台或知识定义，也没有回写旧模板/历史数据。原300/75网格工程clamp保持，不能外推成Word正文表格/输入库内存的全局上限。

本体按DEC-0077-12/22/30等有限范围核对使用时快照、同一配置/保存撤销及草稿安全；本优化不新增业务规则。知识0.3.25/schema1.2.0/P0保持，机械353文件/2849ID不等于本轮全库语义已审。
