## 规则依据与边界

原始知识与源码对照：DEC-0082-03/06/09/10/14–16、`rule.form-reference-runtime`、DEC-0087-02/04/06、DEC-0095；权限解释同时保留DEC-0094对旧声明的精确部分替代。选择规则本身合理：使用记录自己的冻结模板，当前值决定引用依赖，历史原因只在原值完全一致时按原共享规则保留；所有符合既有资格的人员都能到达。

本体角色逐项核对21个有限记录：18范围一致、1精确历史部分替代、2原范围外未决。353知识文件未变，知识0.3.25/schema1.2.0/P0不升级。本体`not-applicable/FINAL`表示无需新增或改写业务知识，不表示没有进行语义核对；这些记录与历史覆盖有交叉，不能新增21个唯一覆盖或宣称全库一致。

原不可修改顶字段的skip及篡改拒绝保持。其余证据按完整拟值调用原共享校验，包括本次没有显式传入的值；没有“省略字段即可免校验证据”的原政策。没有放宽失效引用、缺失附件、签署、审批或只读保护，也没有增加catch后默认通过。已确认的MVP单租户读取资格沿用，完整多租户边界仍按原开放问题处理。

只修新prepare链：已签名的旧IN_REVIEW拟值、历史修订不自动净化、迁移或重签；实际存量未知。不能把本批结果当存量安全证明。发现具体存量时按原审批状态和退回/重建链另核，未经授权不改写已签载荷。

旧GET只具备保存的主值，不猜用户当前正在编辑的某一子行；新页面使用POST携带真实主/行上下文。POST只读，不增加签署/审批资格或修改来源记录。没有schema或索引变更。
