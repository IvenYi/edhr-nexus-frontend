## 本次解释的原始实现

`DesignerInspector.renderReferenceSections`的三个控件分别保存候选对象属性`sourceField`、比较方式`operator`、当前表单取值字段`targetFieldId`。`FormReferenceLookup.query`按全部条件同时满足组合；当前运算符为等于、不等于、文本包含、文本不包含。被依赖字段无值时不返回候选，不忽略该条件；完全空的配置行不构成筛选。

右侧字段为引用时沿现有`conditionValue`读取方式；本轮解释不将其改为原始ID比较，不新增操作符或推导关系。该配置用于限制引用候选，不是报表查询、追溯项查询或自动回填。
