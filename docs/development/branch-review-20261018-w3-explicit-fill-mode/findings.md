实现阶段本体角色另指出 PROCESS 空 ID 的旧提前 continue：调整完整校验以保留精确节点/按钮错误后，该分支仍可能绕过。新增实际发布反例先失败，再将该分支改为明确拒绝，覆盖缺失/null/空串/空白引用。它属于 AUD-H003 的同一发布校验旁路，未扩大为新政策。
