# 本轮源码、兼容与A23

源码根因是旧list在全部DHR任务间以64条keyset取批，在Java判断候选/已办与关键词、累计总数及取页。即使第一页已够20条仍遍历到末尾。真实同源容量方法在旧1ad63009上返回相同个人21条，但执行84次、搬运5309条；新查询仅1次、20条。旧反证只有SQL次数断言失败，零error/skip，不把测试工具前置或夹具错误算产品红。

现list把资格与关键词下推PG，一条NOT MATERIALIZED CTE内分别计算准确总数和当前页，以LEFT JOIN保留空页total。page/size归一化、long偏移、ID倒序保持。SELECT详情/动作投影与轻列表投影共享FROM关系，列表不再读取检查凭证、候选JSON、节点properties等大字段；详情、动作、冻结证据、锁顺序、签署及通知方法不改。

候选正式生产者写字符串数组和布尔unrestricted。列表仍与旧Java当前兼容行为对齐，包括非空集合优先于assignee、空/缺失/标量回退、数值/对象成员及unrestricted既有类型转换；不把这些兼容形状写成新业务政策。SQL各JSON set-returning函数有对应类型CASE，避免有效JSON的scalar/object/array形状导致数据库类型异常。这是已有行为兼容，不是新增默认授权或历史修复。

关键词按原Java strip/Locale.ROOT处理参数，SQL ICU root lower与strpos作字面包含。普通默认lower会使少数Unicode结果不同，不能直接用它让测试变绿；使用真实PG矩阵及迁移运行前置。数据库ICU能力和版本变化边界见index-boundaries.md，不伪造已验证目标生产库。

## 验证安排

原4条H2列表断言迁到真实PG：新native矩阵有独立旧Java过滤oracle；完整应用RecordControlPostgresIntegrationTest新增实际退回→再提交→批准时的待审/已办成员断言，含非候选不可见。H2仍执行真实工作流、电子签署及冻结历史，不模拟PG JSON函数，不删除原业务断言。新增native测试必须设置隔离PG URL白名单并实际执行；环境缺失导致skip不能充当本轮验收。

native列表夹具从canonical原表读取5个查询表的DDL/检查约束、PK/唯一约束及原索引，没有认证全部FK、全库CRUD或浏览器。完整应用另执行实际Liquibase与服务，两个层次分开记录。矩阵比较ID、顺序、内容分页元信息、准确总数、负/极大页、页大小、状态、候选类型、Unicode及字面特殊字符；每次实际查询只传当前页，空页保留一条total行。

初始两轮新夹具分别重复生产对象键、重复同DHR摘要hash/版本键；修正数据身份后保留原约束与错误原件。一次辅助探针把lc_collate当配置参数读取，改读pg_database；一次回滚测试用错本版本Liquibase重载，编译错误原件保留，未执行新测试且旧XML不可计本次结果。旧工作树最初缺vite，补依赖工具链接后才运行真实旧源反证。这些都不算业务缺陷或已通过的运行。

## 健壮性与过度防御

JSON类型CASE、资格优先级、空页total行、long偏移与ICU前置分别对应实际兼容、无结果/深页、整数范围和已证Unicode差异；有具体输入证据，保留。没有大范围catch兜底放行、重复重试、缓存、可配置权限旁路或第二套候选快照。轻投影复用FROM，减少本轮重复关系定义；没有从其他服务复制当前用户或已取得工作流数据反复查询。

一个list调用只发一条SQL，没有Java逐任务SQL或全量内存分页；SQL内部COUNT/分页与候选子查询的执行成本仍需计划评估，不能拿一条SQL声称没有数据库重复工作。两个部分索引各有选择性边界，原索引不删除。CONCURRENTLY与独立changeset不是消除部署风险，invalid失败恢复需要准确索引状态。

## 具体后续拆分边界

本轮只改DhrReviewService的查询入口及投影常量。若继续扩展过滤种类，可抽DhrReviewQueryRepository，拥有同一可见性谓词、COUNT/page SQL、行映射及原生等价矩阵；审批服务继续拥有工作流/对象/DHR锁、冻结核验、人工退回和签署事务，不能连同优化替换业务规则。若大活跃候选集确有负载，再独立设计用户—任务投影及与冻结候选的事务维护/回填方案；不以当前合成极端数据直接启动大重构。

本轮属于W3/W4/W5交叉中的既有查询性能整改；两DHR high、完整外部质量事实/账号/UI/收件人矩阵、文件ACL/DELETE/UNKNOWN/相邻DHR回调、A12和四gap及朋友页/生产弹窗暂缓保持。W6全量含旧已审的健壮性/A23和W7增量继续，盘点、有限源码审查与唯一覆盖不混同。
