### 发现并修复

1. 公共候选查询额外要求创建权限，而记录控制申请采用已登录访问边界。真实普通账号 UI 收到403，见 [失败原件](evidence/baseline-live-candidate-failure.json)。用户于11月3日明确确认本轮对齐；现用 `isAuthenticated()` 读取类型匹配的已发布版本。来源状态、当前修订、冲突申请、签名、审批处理权等写入校验保持。
2. 记录变更、个人填报、个人审批和DHR填报漏用生产执行页已有的 `executionFormValues`：页面输入数字以字符串进入申请，最终生效时被统计投影拒绝，见 [失败原件](evidence/baseline-live-number-failure.json)。四个入口复用既有归一化工具，输入时仍保留文本；只在提交边界按冻结字段类型转换合法数值，子表递归，空白或无效值仍交原校验处理，不改历史值和签名。

另纠正普通表单转办提示：同租户可用用户不局限于原候选集合。普通表单转办不新增签名；手工夹具曾错误设置普通TRANSFER签署事件，已核对原始用户政策与保存/发布校验后纠正夹具，未把它计为产品缺陷。记录控制转办仍保留其独立配置决定的签署机制。
