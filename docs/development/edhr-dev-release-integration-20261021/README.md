## 改动内容

- 原因：不良原因、报废原因两个目录及数据菜单、权限、审计、使用保护；标准原因用途只绑定对应目录单选引用，文字承载补充说明。独立不良明细及报表保留来源，不求和替代报工 NG。原因分类暂缓，报废物料类型仍保留。
- 引用：人员选择器、业务对象选择弹窗、可排序展示字段与方括号拼接、查询条件验证和具体字典选择；物料/产品、批次/SN统一配置入口并按范围限定，身份不依赖显示文本。仅明确生产上下文按显式配置自动带入，设备不自动猜选。同步修正取消字段选中后追溯面板状态及字典详情布局。
- 初始化：生产 master 只加载最终 schema 和 seed 两份 SQL；直接包含原因表、原因菜单/ADMIN 权限、九项追溯预置及签名 TEXT 约束。127 份旧 SQL 移入测试资源，仅用于历史回归，不再进入应用 JAR 或启动链。
- 旧入口：关闭旧 SOP/工艺文档写接口，保留必要读取及当前版本化文档功能；删除两份旧投影 SQL 演示灌数工具，阻断退役追溯配置从保存、冻结、新份及重试生成新记录。
- 本体：修正 107 处初始化来源引用，区分当前实现与历史证据；未合入原因决策重编号为 DEC-0082，保留目标 DEC-0081 委托规则。知识版本保持 0.3.25，未提升既有成熟度。
